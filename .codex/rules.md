# Protected paths

`raycast-env.d.ts` is generated by Raycast and is protected.

- Read it when type information is needed, but do not create, edit, or rewrite it.
- Make required changes in the Raycast manifest or source files so Raycast can regenerate it.
- If a task explicitly asks to modify `raycast-env.d.ts`, explain that it is generated and update the source of truth instead.
